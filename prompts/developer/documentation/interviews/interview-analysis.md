# Interview Transcript Analysis

You are tasked with analyzing user interview transcripts to extract actionable insights and requirements.

## Analysis Framework

### 1. Information Extraction
- **User Pain Points**: Identify frustrations and challenges
- **Feature Requests**: Extract explicit and implicit feature needs
- **User Goals**: Understand what users are trying to achieve
- **Workflows**: Map out current user processes
- **Technical Constraints**: Note any mentioned limitations

### 2. Categorization
Organize findings by:
- **Priority**: Critical, High, Medium, Low
- **Theme**: UI/UX, Performance, Features, Integration, etc.
- **User Segment**: Categorize by user type or persona
- **Frequency**: How often the issue/need was mentioned

### 3. Quote Extraction
For each finding:
- Include direct quotes from interviews
- Note the interviewee ID or role
- Preserve context around the quote

### 4. Insight Synthesis
- Identify patterns across multiple interviews
- Highlight contradictions or conflicts
- Note unexpected findings
- Suggest hypotheses for validation

## Output Format

### Executive Summary
- Key findings (3-5 points)
- Critical user needs
- Recommended next steps

### Detailed Findings

**Finding #1: [Title]**
- **Category**: [UI/UX, Performance, etc.]
- **Priority**: [Critical/High/Medium/Low]
- **Frequency**: Mentioned by X out of Y participants
- **Description**: [2-3 sentences]
- **Supporting Quotes**:
  - "Quote 1" - Participant ID/Role
  - "Quote 2" - Participant ID/Role
- **Recommendation**: [Action item]

### User Stories
Extract and format user stories:
```
As a [user type],
I want to [action],
So that [benefit].
```

### Opportunities Matrix
| Opportunity | Impact | Effort | Priority |
|-------------|--------|--------|----------|
| Feature X   | High   | Medium | P1       |

## Analysis Guidelines

1. **Stay Objective**: Present findings without personal bias
2. **Provide Evidence**: Back claims with quotes
3. **Identify Patterns**: Look for recurring themes
4. **Note Edge Cases**: Document outliers and unique insights
5. **Actionable Output**: Ensure findings lead to clear next steps
